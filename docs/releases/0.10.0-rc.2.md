# DevRelay 0.10.0-rc.2 preview

This release simplifies the supported ChatGPT Desktop on Windows surface while retaining deterministic Core authority and full lifecycle traceability.

## Operator surface

- Eight root operations: `createDevRelay`, `createLocalHost`, `defineModule`, `definePlugin`, `run`, `resume`, `verify`, and `inspect`.
- Seven CLI commands: `init`, `run`, `resume`, `status`, `verify`, `inspect`, and `evidence`.
- Three built-in workflow profiles: `standard`, `fast`, and `high-assurance`.
- Explicit advanced, compatibility, and optional-pack tiers.

## Evidence and compatibility

Historical V0.11 evidence is replayed from immutable version-pinned snapshots. Full evidence can be materialized as checksum-bound release assets, while compact summaries remain reviewable in Git. `compat/v1` is deprecated and supported only through the 0.11 prerelease line.

## Preview boundary

This preview is distributed as GitHub source and an installable tarball. It does not claim stable status, public npm publication, a hosted backend, or a one-click ChatGPT Desktop plug-in. Independent human review is required before stable release. The complete long-lived local reference host remains a 0.11 milestone; rc.2 supplies the bounded Windows host primitives needed for deterministic Desktop dogfooding.
