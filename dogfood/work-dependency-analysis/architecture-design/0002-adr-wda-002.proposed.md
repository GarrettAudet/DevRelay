# Store forward lifecycle traceability and derive reverse traversal

## Status

Proposed

## Context and problem statement

WorkDependencyAnalysis must preserve deterministic Core and gate authority while allowing bounded capability replacement.

## Decision drivers

- Determinism
- Provider neutrality
- Traceability

## Considered options

- OPT-WDA-FORWARD-TRACE
- OPT-WDA-INVERSE-EDGES

## Decision outcome

Chosen: OPT-WDA-FORWARD-TRACE. The selected boundary preserves canonical DevRelay semantics and keeps native tools subordinate.

## Consequences

- Positive: capability implementations remain replaceable.
- Negative: conformance and replay evidence are required for each binding.
