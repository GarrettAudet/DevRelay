# Persist a static authoritative DAG and derive runnable frontiers downstream

## Status

Proposed

## Context and problem statement

WorkDependencyAnalysis must preserve deterministic Core and gate authority while allowing bounded capability replacement.

## Decision drivers

- Determinism
- Provider neutrality
- Traceability

## Considered options

- OPT-WDA-STATIC-DAG
- OPT-WDA-PERSISTED-WAVES

## Decision outcome

Chosen: OPT-WDA-STATIC-DAG. The selected boundary preserves canonical DevRelay semantics and keeps native tools subordinate.

## Consequences

- Positive: capability implementations remain replaceable.
- Negative: conformance and replay evidence are required for each binding.
