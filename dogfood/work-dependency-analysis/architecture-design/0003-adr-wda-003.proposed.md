# Analyze a full work-breakdown snapshot with pinned context slices

## Status

Proposed

## Context and problem statement

WorkDependencyAnalysis must preserve deterministic Core and gate authority while allowing bounded capability replacement.

## Decision drivers

- Determinism
- Provider neutrality
- Traceability

## Considered options

- OPT-WDA-FULL-SNAPSHOT
- OPT-WDA-ADAPTER-SELECTED-CONTEXT

## Decision outcome

Chosen: OPT-WDA-FULL-SNAPSHOT. The selected boundary preserves canonical DevRelay semantics and keeps native tools subordinate.

## Consequences

- Positive: capability implementations remain replaceable.
- Negative: conformance and replay evidence are required for each binding.
