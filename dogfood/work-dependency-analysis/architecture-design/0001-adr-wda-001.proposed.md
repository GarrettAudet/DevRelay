# Keep planning authority in Core and configured gates

## Status

Proposed

## Context and problem statement

WorkDependencyAnalysis must preserve deterministic Core and gate authority while allowing bounded capability replacement.

## Decision drivers

- Determinism
- Provider neutrality
- Traceability

## Considered options

- OPT-WDA-CORE-AUTHORITY
- OPT-WDA-PLUGIN-AUTHORITY

## Decision outcome

Chosen: OPT-WDA-CORE-AUTHORITY. The selected boundary preserves canonical DevRelay semantics and keeps native tools subordinate.

## Consequences

- Positive: capability implementations remain replaceable.
- Negative: conformance and replay evidence are required for each binding.
