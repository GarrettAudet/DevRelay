# Support

DevRelay `0.10.0-rc.x` is an open-source preview. Support is community and
maintainer best effort; there is no service-level agreement.

## Where to ask

- Use a bug report for reproducible defects.
- Use a feature request for proposed behavior or adapters.
- Use `SECURITY.md` for vulnerabilities and never disclose exploit details in
  a public issue.

Include the exact DevRelay version and commit, Node version, Windows version,
invocation or command, expected result, actual result, and the smallest safe
reproduction you can provide.

## Supported environment

The preview supports Node.js 22 and 24 on Windows, with Ubuntu verification as
a portability guard. The intended interactive host is ChatGPT Desktop on
Windows. DevRelay does not provide a hosted backend, managed operations, or a
one-click Desktop plug-in.

Only the current preview line receives fixes. Historical evidence branches and
unreleased development branches are not supported distributions.
